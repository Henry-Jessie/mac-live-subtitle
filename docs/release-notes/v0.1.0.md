# Mac Live Subtitle v0.1.0

The first native macOS release of Mac Live Subtitle.

## Highlights

- Native AppKit menu-bar app and floating subtitle panel.
- Direct system-audio capture through ScreenCaptureKit; BlackHole is no
  longer required.
- FunASR Realtime streaming transcription with semantic-punctuation and VAD
  modes.
- Optional translation through DeepSeek, Gemini, or a custom
  OpenAI-compatible endpoint.
- English and Chinese settings interface.
- Local API-key storage without Keychain authorization prompts.
- Adjustable subtitle opacity, source font size, and translation font size.

## Requirements

- macOS 13 or later.
- Apple Silicon (`arm64`).
- Alibaba Cloud Model Studio API key for FunASR Realtime.
- A provider API key when translation is enabled.

## Install

1. Download `Mac-Live-Subtitle-v0.1.0-macos-arm64.zip`.
2. Unzip it and move **Mac Live Subtitle.app** to `/Applications`.
3. Try to open the app once.
4. If macOS blocks it, open **System Settings → Privacy & Security** and
   choose **Open Anyway**.
5. Start capture, approve **Screen & System Audio Recording**, then quit and
   reopen the app.

## Release assets

- `Mac-Live-Subtitle-v0.1.0-macos-arm64.zip` — signed standalone application.
- `SHA256SUMS.txt` — SHA-256 checksum for the application archive.

## Known limitations

- The application is Apple Silicon only.
- The release uses a stable self-signed certificate and is not notarized by
  Apple, so the first launch requires the Open Anyway flow.
- Transcription and translation use cloud services and may incur provider
  charges.

# Mac Live Subtitle v0.1.0 中文说明

这是 Mac Live Subtitle 的首个原生 macOS 发行版。

## 主要更新

- 原生 AppKit 菜单栏应用和悬浮字幕窗口。
- 使用 ScreenCaptureKit 直接捕获系统音频，不再需要 BlackHole。
- FunASR Realtime 流式识别，支持语义标点和 VAD 分句。
- 支持 DeepSeek、Gemini 和兼容 OpenAI 接口的自定义翻译服务。
- 设置界面支持中文和英文。
- API Key 保存在本机，不会触发钥匙串授权弹窗。
- 可调整字幕背景透明度、原文字号和译文字号。

## 系统要求

- macOS 13 或更高版本。
- Apple Silicon（`arm64`）。
- FunASR Realtime 需要阿里云百炼 API Key。
- 启用翻译时需要相应服务商的 API Key。

## 安装

1. 下载 `Mac-Live-Subtitle-v0.1.0-macos-arm64.zip`。
2. 解压后将 **Mac Live Subtitle.app** 移入 `/Applications`。
3. 尝试打开一次应用。
4. 如果 macOS 阻止启动，前往“**系统设置 → 隐私与安全性**”，点击
   “**仍要打开**”。
5. 开始捕获并允许“**屏幕与系统音频录制**”，然后完全退出并重新打开应用。

## 已知限制

- 当前只支持 Apple Silicon。
- 应用使用固定的自签名证书，尚未经过 Apple 公证，首次启动需要执行
  “仍要打开”流程。
- 识别和翻译依赖云端服务，可能产生服务商费用。
